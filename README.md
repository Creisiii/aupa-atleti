# aupa-atleti

Personal Atlético de Madrid hub: matches, lineups, advanced match stats,
automatic post-match summaries and event-driven notifications.

Backend in .NET, frontend in Angular. Work in progress.

## Planned scope

1. Matches, lineups and xG for Atlético de Madrid
2. Automatic match summary and a notification when each match ends
3. Lineup and formation editor
4. Signing recommendations by position across 10 leagues
5. Private media gallery, off by default

## Configuration

API keys and media files never live in this repository. Keys are read from
environment variables; media is stored in a private folder outside the repo.
